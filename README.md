# Smart Hospital & Resource Allocation System

A C-based, menu-driven hospital management system

## Overview

The system is designed to manage basic hospital operations, including:

- Patient registration
- Hospital specialty and ward information
- Bed occupancy and automatic bed allocation
- Patient priority management
- Patient billing and cost calculations
- Hospital performance reports
- Saving patient and bed records to text files

The project demonstrates fundamental C programming concepts such as arrays, functions, strings, loops, conditionals, modular programming, and basic file handling.
